Häufige Java-Fehler

Hier fehlt ein Semikolon ;

class Example { void go() { int n = 1

Java hat die Lücke an dieser Stelle bemerkt. Wenn du sie hier nicht siehst, schau ans Ende der Zeile darüber: Dort fehlt es oft.

Korrektur
class Example { void go() { int n = 1;
} }

Java kennt keine Variable namens scor

class Example { int score = 1; int go() { return scor; } }

Prüfe die Schreibweise (Java unterscheidet Groß- und Kleinschreibung!) und ob die Variable vor dieser Zeile deklariert ist, im selben { }-Block oder als Attribut der Klasse.

Korrektur
class Example { int score = 1; int go() { return score; } }

Java kennt keine Methode namens og()

class Example { void go() { og(); } }

Prüfe die Schreibweise (Java unterscheidet Groß- und Kleinschreibung!) und ob die Methode zu diesem Objekt gehört. Die API-Hilfe zeigt die Methoden der Bibliothek.

Korrektur
class Example { void go() { go(); } }

Java kennt keine Klasse namens Strng

class Example { Strng text; }

Prüfe die Schreibweise: Klassennamen beginnen mit einem Großbuchstaben (String, Sprite). Ist es eine Klasse deines Projekts, muss ihre Datei Strng.java heißen.

Korrektur
class Example { String text; }

= speichert einen Wert. Zum Vergleichen schreibst du ==

class Example { void go() { int n = 0; if (n = 2) {} } }

In einer Bedingung versucht x = 2, die 2 in x zu speichern. Zahlen vergleichst du mit x == 2, Texte mit a.equals(b).

Korrektur
class Example { void go() { int n = 0; if (n == 2) {} } }

Am Ende dieser Methode fehlt ein return

class Example { int score() { int n = 4; } }

Die Methode verspricht einen Wert, aber auf einem Weg durch sie wird nichts zurückgegeben. Jeder Weg muss mit return und einem Wert enden.

Korrektur
class Example { int score() { int n = 4; return n; } }

Die Datei endet zu früh: Eine schließende geschweifte Klammer } fehlt

class Example { void go() {}

Zu jeder { gehört eine passende }. Prüfe, ob jede Methode und die Klasse selbst geschlossen sind.

Korrektur
class Example { void go() {} }

Die Klammer ( aus Zeile 1 braucht ), hier steht aber }

class Example { void go() { if (true { } } }

Schließe die Klammer aus Zeile 1 mit dem passenden Zeichen. Runde (), eckige [] und geschweifte Klammern {} haben verschiedene Aufgaben.

Korrektur
class Example { void go() { if (true) { } } }

Die Klammer [ aus Zeile 3 braucht ], hier steht aber )

    int[] a = new int[3);

Schließe die Klammer aus Zeile 3 mit dem passenden Zeichen. Runde (), eckige [] und geschweifte Klammern {} haben verschiedene Aufgaben.

Korrektur
class Example {
  void go() {
    int[] a = new int[3];
  }
}

Diesem Zeichen fehlt das schließende '

class Example { char c = 'x; }

Setze ein Zeichen zwischen zwei gerade einfache Anführungszeichen, zum Beispiel 'x'. Für längeren Text brauchst du doppelte Anführungszeichen.

Korrektur
class Example { char c = 'x'; }

double passt nicht ohne Verlust in int

class Example { int n = 1.5; }

Aus 2.7 würde zum Beispiel 2. Mach die Variable zu einem double, oder wandle bewusst um, indem du (int) vor den Wert schreibst, zum Beispiel (int) getX().

Korrektur
class Example { double n = 1.5; }

Text kann nicht als int benutzt werden

class Example { int n = "42"; }

Auch "42" ist Text und keine Zahl. Wandle ihn um: Integer.parseInt(text) oder Double.parseDouble(text).

Korrektur
class Example { int n = 42; }

n hat noch keinen Wert

class Example { int go() { int n; return n; } }

Gib ihr dort, wo du sie deklarierst, einen Startwert, zum Beispiel int n = 0;

Korrektur
class Example { int go() { int n = 0; return n; } }

n gibt es hier schon

class Example { void go() { int n = 1; int n = 2; } }

Zwei Variablen oder Methoden an derselben Stelle können nicht gleich heißen. Benenne eine um. Um eine vorhandene Variable zu ändern, lass den Typ weg: x = 5; statt int x = 5;

Korrektur
class Example { void go() { int n = 1; n = 2; } }

go braucht (int), bekommt aber (nichts)

class Example { void go(int n) { go(); } }

Prüfe Anzahl, Reihenfolge und Typen der Werte in den Klammern.

Korrektur
class Example { void go(int n) { go(1); } }

Diesem Text fehlt das schließende "

class Example { String s = "hello; }

Ein Text beginnt und endet mit einem geraden Anführungszeichen ". Er kann nicht in der nächsten Zeile weitergehen.

Korrektur
class Example { String s = "hello"; }

break funktioniert nur in einer Schleife oder einem switch

class Example { void go() { break; } }

Um eine Methode früher zu verlassen, benutze return.

Korrektur
class Example { void go() { for (int i=0;i<3;i++) { break; } } }

Diese Methode ist void und kann keinen Wert zurückgeben

class Example { void go() { return 1; } }

Entferne den Wert hinter return, oder ersetze void durch den Typ des Werts, zum Beispiel public int anzahl().

Korrektur
class Example { int go() { return 1; } }

Eine Methode kann nicht in einer anderen Methode stehen

class Example { void go() { void inner() {} } }

Schließe die Methode darüber mit }, bevor du eine neue beginnst.

Korrektur
class Example { void go() {} void inner() {} }

n ist final und kann sich nicht ändern

class Example { void go() { final int n=1; n=2; } }

Entferne final dort, wo n deklariert ist, wenn sich der Wert ändern soll.

Korrektur
class Example { void go() { int n=1; n=2; } }

Schreibe extends statt exends

public class Welt exends Spielwelt {

Mit extends erbt Welt von Spielwelt.

Korrektur
public class Welt extends Spielwelt {
}
class Spielwelt {}

Schreibe class statt cass

public cass Welt extends Spielwelt {

class beginnt die Deklaration von Welt. Nach class steht der Klassenname.

Korrektur
public class Welt extends Spielwelt {
}
class Spielwelt {}

Schreibe public statt pulic

pulic class Welt extends Spielwelt {

Mit public können andere Klassen Welt verwenden.

Korrektur
public class Welt extends Spielwelt {
}
class Spielwelt {}
