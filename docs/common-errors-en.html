Common Java errors

A semicolon ; is missing here

class Example { void go() { int n = 1

Java noticed the gap at this spot. If you cannot see it here, look at the end of the line above: that is often where it is missing.

Fix
class Example { void go() { int n = 1;
} }

Java does not know a variable named scor

class Example { int score = 1; int go() { return scor; } }

Check the spelling (Java is case-sensitive!) and that the variable is declared before this line, in the same { } block or as a field of the class.

Fix
class Example { int score = 1; int go() { return score; } }

Java does not know a method named og()

class Example { void go() { og(); } }

Check the spelling (Java is case-sensitive!) and that the method belongs to this object. The API help lists the methods of the library.

Fix
class Example { void go() { go(); } }

Java does not know a class named Strng

class Example { Strng text; }

Check the spelling: class names start with a capital letter (String, Sprite). If it is a class of your project, its file must be named Strng.java.

Fix
class Example { String text; }

= stores a value. To compare, write ==

class Example { void go() { int n = 0; if (n = 2) {} } }

In a condition, x = 2 tries to store 2 in x. Compare numbers with x == 2 and texts with a.equals(b).

Fix
class Example { void go() { int n = 0; if (n == 2) {} } }

A return is missing at the end of this method

class Example { int score() { int n = 4; } }

The method promises a value, but on some path through it nothing is returned. Make sure every path ends with return and a value.

Fix
class Example { int score() { int n = 4; return n; } }

The file ends too early: a closing brace } is missing

class Example { void go() {}

Every { needs a matching }. Check that each method and the class itself are closed.

Fix
class Example { void go() {} }

The ( opened on line 1 needs ), but this is }

class Example { void go() { if (true { } } }

Match the closing bracket to the opening bracket on line 1. Round (), square [] and curly braces {} have different jobs.

Fix
class Example { void go() { if (true) { } } }

The [ opened on line 3 needs ], but this is )

    int[] a = new int[3);

Match the closing bracket to the opening bracket on line 3. Round (), square [] and curly braces {} have different jobs.

Fix
class Example {
  void go() {
    int[] a = new int[3];
  }
}

This character is missing its closing '

class Example { char c = 'x; }

Put one character between two straight single quotes, for example 'x'. Use double quotes for longer text.

Fix
class Example { char c = 'x'; }

double does not fit into int without losing part of it

class Example { int n = 1.5; }

For example 2.7 would become 2. Make the variable a double, or convert on purpose by writing (int) before the value, for example (int) getX().

Fix
class Example { double n = 1.5; }

Text cannot be used as int

class Example { int n = "42"; }

Even "42" is text, not a number. Convert it: Integer.parseInt(text) or Double.parseDouble(text).

Fix
class Example { int n = 42; }

n has no value yet

class Example { int go() { int n; return n; } }

Give it a start value where you declare it, for example int n = 0;

Fix
class Example { int go() { int n = 0; return n; } }

n already exists here

class Example { void go() { int n = 1; int n = 2; } }

Two variables or methods in the same place cannot have the same name. Rename one. To change an existing variable, leave out the type: x = 5; instead of int x = 5;

Fix
class Example { void go() { int n = 1; n = 2; } }

go needs (int) but gets (nothing)

class Example { void go(int n) { go(); } }

Check the number, the order and the types of the values in the brackets.

Fix
class Example { void go(int n) { go(1); } }

This text is missing its closing "

class Example { String s = "hello; }

A text starts and ends with a straight double quote ". It cannot continue on the next line.

Fix
class Example { String s = "hello"; }

break only works inside a loop or switch

class Example { void go() { break; } }

To leave a method early, use return.

Fix
class Example { void go() { for (int i=0;i<3;i++) { break; } } }

This method is void, so it cannot return a value

class Example { void go() { return 1; } }

Remove the value after return, or replace void with the type of the value, for example public int count().

Fix
class Example { int go() { return 1; } }

A method cannot be inside another method

class Example { void go() { void inner() {} } }

Close the method above with } before you start a new one.

Fix
class Example { void go() {} void inner() {} }

n is final and cannot change

class Example { void go() { final int n=1; n=2; } }

Remove final where n is declared if its value should change.

Fix
class Example { void go() { int n=1; n=2; } }

Write extends instead of exends

public class Welt exends Spielwelt {

extends tells Java that Welt inherits from Spielwelt.

Fix
public class Welt extends Spielwelt {
}
class Spielwelt {}

Write class instead of cass

public cass Welt extends Spielwelt {

class starts the declaration of Welt. Write the class name after class.

Fix
public class Welt extends Spielwelt {
}
class Spielwelt {}

Write public instead of pulic

pulic class Welt extends Spielwelt {

public lets other classes use Welt.

Fix
public class Welt extends Spielwelt {
}
class Spielwelt {}
